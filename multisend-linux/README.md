# MultiSend Gemini Manager

این مخزن برای مدیریت چند حساب واقعی Google در وب‌سایت رسمی Gemini بازطراحی می‌شود؛ بدون Gemini API و بدون واردکردن API Key.

## معماری مسیر Gemini

- یک پنل واحد برای مدیریت ۵ جایگاه حساب Gemini.
- هر جایگاه یک پروفایل مرورگر Chromium مستقل و ماندگار دارد.
- کاربر در اولین اتصال، پنجره همان حساب را باز می‌کند و ورود Google، گذرواژه، تأیید دومرحله‌ای و هر CAPTCHA را شخصاً انجام می‌دهد.
- برای هر حساب یک یا دو تصویر مستقل انتخاب می‌شود.
- یک پرامپت مشترک برای حساب‌های انتخاب‌شده ارسال می‌شود.
- ارسال‌ها به‌صورت ترتیبی انجام می‌شوند؛ وضعیت هر حساب جداگانه گزارش می‌شود.
- نشست‌ها در پوشه multisend-linux/sessions/ روی همان دستگاه ذخیره می‌شوند.

## اجرا در Linux / Debian / محیط Linux داخل Termux

    cd chatgptmulti/multisend-linux
    chmod +x install-debian.sh start-debian.sh
    ./install-debian.sh
    ./start-debian.sh

سپس پنل را در مرورگر باز کنید:

    http://127.0.0.1:8787

برای استفاده از پنجره‌های مرورگر، محیط گرافیکی دسکتاپ یا VNC لازم است. این backend روی Android خام یا داخل APK اجرا نمی‌شود.

## راه‌اندازی حساب‌ها

۱. روی «ورود / اتصال» برای هر حساب بزنید.
۲. در پنجره Chromium بازشده، با حساب Google موردنظر وارد Gemini شوید.
۳. مراحل امنیتی Google را خودتان تکمیل کنید.
۴. پس از ورود، وضعیت حساب را در پنل تازه‌سازی کنید.
۵. برای هر حساب یک یا دو تصویر انتخاب کنید و پرامپت مشترک را وارد کنید.

هیچ رمز Google یا API Key در این برنامه دریافت یا ذخیره نمی‌شود؛ داده نشست مرورگر در پروفایل محلی همان حساب باقی می‌ماند.

## APIهای محلی

- GET /api/accounts — وضعیت پنج جایگاه حساب
- POST /api/accounts/{account_id}/open — بازکردن Gemini برای ورود دستی
- POST /api/batch — ایجاد صف با پرامپت مشترک و تخصیص ۱ یا ۲ عکس به هر حساب
- GET /api/jobs — وضعیت هر حساب در صف
- POST /api/stop — توقف صف
- POST /api/reset — پاک‌کردن نتایج صف

## محدودیت‌ها و صداقت فنی

- این روش از رابط وب رسمی Gemini استفاده می‌کند و API نیست؛ اما Google ممکن است ورود یا خودکارسازی مرورگر را محدود کند.
- ورود، تأیید هویت و حل CAPTCHA فقط توسط خود کاربر انجام می‌شود. این پروژه هیچ محدودیت امنیتی یا حفاظتی را دور نمی‌زند.
- رابط داخلی Gemini ممکن است تغییر کند؛ در آن صورت selectorهای Playwright باید به‌روزرسانی شوند.
- تشخیص پایان پاسخ و نتیجه تصویر ممکن است در برخی نسخه‌های Gemini نیازمند بازبینی دستی باشد. وضعیت VERIFY_IN_GEMINI به همین منظور است.
- ارسال گروهی می‌تواند با محدودیت حساب، سهمیه، صف انتظار یا قوانین سرویس مواجه شود؛ موفقیت همه حساب‌ها تضمین‌شده نیست.
- پوشه‌های sessions/ و uploads/ حاوی داده خصوصی هستند؛ آن‌ها را عمومی یا در Git ثبت نکنید.

## وضعیت برنامه Android

ماژول Android موجود در این مخزن نسخه قدیمی مبتنی بر OpenAI API است و هنوز به مدیر نشست‌های مرورگر Gemini متصل نشده است. این ماژول نباید به‌عنوان نسخه Android آماده Gemini معرفی یا استفاده شود. مسیر جدید Gemini در حال حاضر در بخش Linux/browser manager پیاده‌سازی می‌شود.
