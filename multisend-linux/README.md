# MultiSend Control Center

نسخه جدید MultiSend برای اجرای چند Session مستقل مرورگر روی Linux/Termux + XFCE/VNC است.

## چرا این نسخه؟

نسخه Android قبلی با Accessibility مجبور بود اپ‌ها را foreground کند و بین آن‌ها جابه‌جا شود. این روش می‌تواند باعث باز و بسته‌شدن مداوم اپ‌ها و گیرکردن کنترل گوشی شود. این مسیر عمداً کنار گذاشته شده است.

نسخه جدید:

- هیچ اپ ChatGPT اندروید را کنترل نمی‌کند.
- برای هر مقصد یک Chromium profile مستقل دارد.
- Jobها با `asyncio.gather` همزمان dispatch می‌شوند.
- خرابی یک Session باعث توقف Sessionهای دیگر نمی‌شود.
- دکمه **توقف همه** در Control Center وجود دارد.
- پروفایل مرورگرها داخل `sessions/` باقی می‌مانند.
- برای اجرای گرافیکی، XFCE + VNC توصیه می‌شود.

## نصب داخل Debian

```bash
cd ~/chatgptmulti/multisend-linux
chmod +x install-debian.sh start-debian.sh
./install-debian.sh
./start-debian.sh
```

بعد در مرورگر یا VNC Viewer باز کنید:

`http://127.0.0.1:8787`

## Sessionها

در اولین اجرای هر Session، پنجره Chromium باز می‌شود. وارد حساب موردنظر شوید. اطلاعات ورود در profile همان Session ذخیره می‌شود.

مثلاً:

```text
account1,account2,account3
```

هر Session باید متعلق به محیط/حسابی باشد که خود کاربر مجاز به استفاده از آن است.

## محدودیت مهم

این پروژه محدودیت‌ها یا سیاست‌های سرویس را دور نمی‌زند و تضمین نمی‌کند که چند حساب/Session همیشه مجاز یا بدون محدودیت کار کنند. هدف پروژه فقط مدیریت مستقل چند مرورگر و اجرای موازی Jobهاست.

## وضعیت فعلی

این Backend یک پایه واقعی برای معماری جدید است، اما selectorهای رابط ChatGPT ممکن است با تغییرات وب‌سایت نیاز به به‌روزرسانی داشته باشند. قبل از استفاده در Batchهای بزرگ، ابتدا با **یک Session و یک تصویر** تست شود.
