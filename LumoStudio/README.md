# Lumo Studio

اپلیکیشن اندروید برای گروه‌بندی هوشمند عکس‌های اصلی و نسخه‌های ساخته‌شده از آن‌ها
(ویرایش، برش، تغییر رنگ و …)، بازبینی سریع، مقایسه‌ی سه‌حالته و خروجی منظم با نام‌گذاری زنده.

## امکانات

- **تطبیق چندلایه روی دستگاه**: dHash + pHash + همبستگی ساختار لبه (Sobel). مقاوم به تغییر رنگ، کنتراست و کمی برش.
- **اطمینان واقعی**: فاصله‌ی بهترین و دومین کاندید محاسبه می‌شود؛ تطبیق‌های مبهم به صف بازبینی می‌روند.
- **بازبینی با کشیدن کارت**: راست = تأیید، چپ = رد.
- **مقایسه**: نوار کشویی بین عکس اصلی و هر نسخه.
- **امتیاز و بهترین**: ستاره‌ی ۱ تا ۵ و علامت «بهترین».
- **خروجی**: الگوی نام‌گذاری (`{group} {role} {n} {name} {ext}`)، ساختار پوشه، پوشه‌ی `_Unsorted`، فایل `manifest.csv` و ZIP اختیاری.
- **حریم خصوصی**: بدون اینترنت، بدون حساب، بدون ارسال عکس. فایل‌های اصلی هرگز جابه‌جا یا حذف نمی‌شوند؛ خروجی فقط کپی می‌سازد.
- **ظاهر**: حالت سیستم/تاریک/روشن و سه رنگ نور.

## امکانات نسخه‌ی ۲

مدیریت چندپوشه‌ای، مقایسه‌ی پوشه‌ها، تغییر نام/انتقال/کپی هوشمند، فایل‌های تکراری، فیلتر و علامت و دسته‌بندی،
تبدیل فرمت و فشرده‌سازی، داشبورد، گزارش خطا، سلامت پروژه، تاریخچه و بازگشت، پردازش پس‌زمینه با اعلان،
ZIP چندگانه، الگوهای نام‌گذاری، پیش‌نمایش و اشتراک خروجی، چندپروژه‌ای، پشتیبان‌گیری و انتقال به گوشی دیگر،
قفل عملیات حساس، اسکن هوشمند و بازیابی اضطراری.
جزئیات روش و فایل هر قابلیت: [`docs/FEATURES.md`](docs/FEATURES.md)

## ساخت APK

### روی گوشی (بدون کامپیوتر)
1. این پوشه را در یک مخزن GitHub قرار بده (Push).
2. از تب **Actions** اجرای `Build Android APK` را ببین.
3. بعد از اتمام، فایل `LumoStudio-debug` را از بخش Artifacts دانلود و نصب کن
   (باید «نصب از منابع ناشناس» را برای مرورگر یا مدیر فایل روشن کنی).

### با Android Studio
1. پوشه را با Android Studio باز کن (Hedgehog یا جدیدتر).
2. Gradle Sync را اجرا کن؛ اگر Wrapper نبود، `gradle wrapper --gradle-version 8.9` را در ترمینال اجرا کن.
3. `Run ▶` یا `Build > Build APK`.

## نکات فنی

- حداقل نسخه‌ی اندروید: 8.0 (API 26). نسخه‌ی هدف: 35.
- فونت پیش‌فرض سیستم است؛ برای فونت وزیرمتن می‌توانی فایل `.ttf` را در `res/font` بگذاری و در `Theme.kt` به `FontFamily` بدهی.
- تطبیق نسبت به چرخش تصویر (۹۰ درجه) حساس است؛ نسخه‌هایی که چرخیده‌اند را دستی وصل کن.
- برای مجموعه‌های خیلی بزرگ (هزاران عکس)، تحلیل اولیه چند دقیقه طول می‌کشد؛ نتیجه در `project.json` ذخیره می‌شود.
- تصمیم‌های دستی (تأیید، رد، تخصیص) با تغییر حساسیت یا تحلیل مجدد حذف نمی‌شوند.
