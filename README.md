# MultiSend Gemini Manager

هدف این پروژه مدیریت چند حساب واقعی Google در وب‌سایت رسمی Gemini است؛ بدون استفاده از Gemini API و بدون نیاز به API Key.

## آنچه در مسیر جدید پیاده‌سازی شده

- پنل واحد برای پنج حساب Gemini
- نگهداری نشست مرورگر جداگانه برای هر حساب
- ورود دستی و امن توسط خود کاربر در صفحه رسمی Google
- یک پرامپت مشترک برای همه حساب‌های انتخاب‌شده
- انتخاب یک یا دو تصویر اختصاصی برای هر حساب
- اجرای ترتیبی درخواست‌ها و نمایش وضعیت مستقل هر حساب
- توقف صف و بازکردن گفت‌وگوی هر حساب برای بررسی نتیجه

## اجرای نسخه Browser Manager

برای اجرا به Linux دسکتاپ یا محیط Debian گرافیکی با Chromium نیاز است. دستورهای نصب و اجرا در فایل multisend-linux/README.md قرار دارند.

## نکته مهم درباره Android

ماژول Android موجود در این مخزن از نسخه قبلی پروژه باقی مانده و هنوز به جریان Gemini بدون API متصل نشده است؛ بنابراین APK فعلی را نسخه آماده Gemini در نظر نگیرید. مسیر Gemini در حال حاضر در multisend-linux پیاده‌سازی شده است.

## محدودیت‌ها

این پروژه رابط وب رسمی Gemini را از طریق مرورگر کنترل می‌کند. تغییرات سایت ممکن است خودکارسازی را مختل کند و Google ممکن است بعضی نشست‌ها یا درخواست‌ها را محدود کند. ورود، گذرواژه، تأیید دومرحله‌ای و CAPTCHA فقط توسط خود کاربر انجام می‌شود. هیچ محدودیت امنیتی دور زده نمی‌شود و موفقیت همه درخواست‌ها تضمین‌شده نیست.
